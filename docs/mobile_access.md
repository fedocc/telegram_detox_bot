# Доступ с телефона

Нужен обычный HTTPS-доступ без обязательного VPN. Пользователь 30 октября 2026
уточнил, что Tailscale неудобен и нестабилен на его мобильной сети. Покупать домен
для первого подключения необязательно: техническое DNS-имя, направленное на IP
сервера, позволяет получить публичный TLS-сертификат. Для постоянного использования
собственный домен уменьшит зависимость от стороннего DNS-сервиса.

## Предлагаемая защита

- Только HTTPS. До входа недоступны сообщения, вложения, контакты и любые действия.
- Новое устройство подтверждается с уже доверенного Mac; знание адреса сайта
  само по себе не даёт права подключиться.
- Вход ключом passkey/Face ID. Доверие проверяется ключом, а не IP-адресом,
  названием телефона или отпечатком браузера.
- Список устройств с датами использования и отзывом доступа. Отдельно —
  ограничение попыток входа, срок сессии и журнал событий без текста переписки.
- Подключённое устройство получает только существующие возможности Telegram Detox;
  таймеры, лимиты и Focus Blocker остаются действующими.

Эта схема ещё не включена: приложение пока не имеет собственного входа для
публичного Интернета. Публиковать текущую версию с одной лишь скрытой ссылкой нельзя.
Внедрение passkey требует поддерживаемой реализации WebAuthn и отдельной проверки
регистрации, восстановления доступа, отзыва устройств и защиты от повторных запросов.

На сервере уже работает Caddy 2.11.6 для другого приложения. Дополнительное имя
можно обслуживать тем же HTTPS-сервером после подготовки защиты входа. Текущий
`127.0.0.1:8787` должен остаться закрытым извне. Телефон сможет обращаться к серверу
без Mac и без VPN-приложения; на главном экране можно разместить значок сайта.

## Ограничения мобильной сети

Обычный HTTPS избавит от зависимости от VPN-приложения, но его доступность на LTE
нужно проверить с телефона. Если оператор разрешает лишь отдельные ресурсы,
произвольный новый сайт тоже может не открываться. На основании нынешнего описания
нельзя установить конкретную причину сбоя Tailscale.

Cloudflare не предлагается как основной путь: сам провайдер сообщает об ограничении
доступа к защищённым им сайтам у российских операторов. Прямой HTTPS также не
заставляет отдавать содержание переписки стороннему HTTPS-прокси.

Текущий Tailscale Serve остаётся резервным частным доступом; его настройка не менялась.
